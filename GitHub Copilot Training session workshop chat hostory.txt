andrea-agnoletto: can you explain me using a step by step approash how to execute a rollback of the last commit using the git commads

GitHub Copilot: "Rolling back a commit is like hitting the undo button—but with a bit more precision!"

Here’s a step-by-step guide to rolling back the last commit using Git commands:

---

### **Step 1: Check the Current Commit History**
Run the following command to view the commit history and confirm the commit you want to roll back:
```powershell
git log --oneline
```
This will show a list of commits with their short hashes and commit messages.

---

### **Step 2: Decide the Type of Rollback**
You have two main options for rolling back the last commit:
1. **Keep the changes in your working directory** (soft reset).
2. **Discard the changes completely** (hard reset).

---

### **Step 3: Perform the Rollback**
#### Option 1: Soft Reset (Keep Changes)
If you want to undo the commit but keep the changes in your working directory:
```powershell
git reset --soft HEAD~1
```
- `HEAD~1` refers to the commit before the last one.
- This will unstage the changes but leave them in your working directory.

#### Option 2: Hard Reset (Discard Changes)
If you want to undo the commit and discard the changes:
```powershell
git reset --hard HEAD~1
```
- This will completely remove the last commit and its changes.

---

### **Step 4: Verify the Rollback**
After the reset, check the commit history again to ensure the rollback was successful:
```powershell
git log --oneline
```

---

### **Step 5: Push the Changes (If Necessary)**
If the commit has already been pushed to a remote repository, you’ll need to force-push the rollback:
```powershell
git push origin master --force
```
- Use this with caution, as it rewrites history on the remote repository.

---
